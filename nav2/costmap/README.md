# Costmap

## 本章の目的

本章では，Nav2におけるコストマップの役割と確認方法をまとめる．

コストマップは，地図情報やセンサ情報をもとに，
ロボットが通行可能な領域，障害物領域，障害物周辺の危険領域を表現するものである．

Nav2では，主に以下の2種類のコストマップが使用される．

| 種類 | 役割 |
|---|---|
| global costmap | 経路計画で使用される大域的なコストマップ |
| local costmap | 経路追従や障害物回避で使用される局所的なコストマップ |

## 本章で確認する内容

1. costmapの概要
2. global costmapとlocal costmapの違い
3. costmap layerの構成
4. RVizでの確認方法
5. 調整対象パラメータ
6. 実機走行で確認した問題
