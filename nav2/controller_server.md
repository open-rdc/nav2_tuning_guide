# ローカルプランナー / コントローラサーバー (controller_server)

プランナーサーバーが生成したグローバルパス（全体経路）に沿って、ロボットが実際にどう動くか（速度と角速度）を計算するノードです。センサー情報から周囲の障害物を避けつつ、経路に追従するための「ローカルパス」をリアルタイムに生成します。

ORNE-boxではプラグインとして **`DWBLocalPlanner`** を使用しています。

## 基本パラメータ

`nav2_params.yaml` 内の `controller_server` 名前空間で定義されています。

### 🌟 重要なパラメータ（調整の頻度：高）

#### 1. ゴール到達判定 (`goal_checker`)
ロボットが目標地点に到達したとみなす条件です。
*   **`xy_goal_tolerance`** (現在値: 2.0)
    *   意味: 目標地点に対する距離の許容誤差(m)。
    *   **調整のコツ:** 現在値が `2.0` とかなり広めに設定されています。ウェイポイントナビゲーションにおいて、各ポイントで厳密に停止せずにスムーズに通過させるための設定と推測されます。
*   **`yaw_goal_tolerance`** (現在値: 3.14)
    *   意味: 目標地点に対する角度の許容誤差(rad)。`3.14`（約180度）は、ロボットの向きを問わず距離の条件を満たせば到達とみなす設定です。

#### 2. DWBローカルプランナーの速度・加速度設定 (`FollowPath`)
ロボットの運動性能に関する制限です。
*   **`max_vel_x`** (現在値: 0.6) / **`min_vel_x`** (現在値: 0.0)
    *   意味: 前進の最大・最小速度(m/s)。ロボットを後退させたくないため最小速度は `0.0` に設定されています。
*   **`max_vel_theta`** (現在値: 0.7)
    *   意味: 最大回転速度(rad/s)。
*   **`acc_lim_x`** (現在値: 1.0) / **`decel_lim_x`** (現在値: -2.5)
    *   意味: 前進の最大加速度と最大減速度(m/s^2)。
*   **`sim_time`** (現在値: 1.7)
    *   意味: ローカルパスをどれくらい先までフォワードシミュレーションするかの時間(s)。
    *   **調整のコツ:** 大きくしすぎるとCPU負荷が高くなります。デフォルトの `1.7` 付近はバランスの良い数値です。

#### 3. 評価関数（Critics）の重み設定 (`FollowPath`内)
生成したローカルパスの良し悪しを採点するための重み付けパラメータです。ROS 1時代の `pdist_scale` や `occdist_scale` 等をさらに細分化したものになります。
*   **`PathDist.scale`** (現在値: 64.0)
    *   意味: グローバルパスにどれだけ忠実に追従するかの重み。大きいほど経路から外れにくくなります。
*   **`PathAlign.scale`** (現在値: 48.0)
    *   意味: ロボットの向きをグローバルパスの方向にどれだけ合わせるかの重み。
*   **`GoalDist.scale`** (現在値: 16.0) / **`GoalAlign.scale`** (現在値: 16.0)
    *   意味: ローカルな目標地点への近さと向きの重み。
*   **`BaseObstacle.scale`** (現在値: 0.08)
    *   意味: 障害物からどれだけ距離を取るかの重み。
*   **`RotateToGoal.scale`** (現在値: 32.0)
    *   意味: ゴール到達時の回転動作に関する重み。

### 🔧 その他の基本パラメータ

*   **`controller_frequency`** (現在値: 10.0)
    *   意味: 速度指令（cmd_vel）を計算・出力する周波数(Hz)。
*   **`use_realtime_priority`** (現在値: true)
    *   意味: OSのプロセス優先度を上げて、制御周期（10Hz）の乱れを防ぐための設定です。CPU負荷の安定化に寄与します。
*   **スタック判定 (`progress_checker`)**
    *   **`required_movement_radius`** (現在値: 0.5) / **`movement_time_allowance`** (現在値: 20.0)
        *   意味: `20.0`秒間に `0.5`m 以上移動できていない場合、「ロボットがスタックした（進捗がない）」と判定し、リカバリー動作等にフェーズを移行させるための設定です。
*   **`use_sim_time`** (現在値: False)
    *   意味: シミュレーション内の時間を使用するかどうか。実機を動かす場合は `False` にします。
