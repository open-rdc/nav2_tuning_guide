# パス平滑化サーバー (smoother_server)

プランナーが生成したカクカクしたグローバルパスを、ロボットが滑らかに追従できるように曲線を滑らかに補正（スムージング）するノードです。

## 基本パラメータ

`nav2_params.yaml` 内の `smoother_server` 名前空間で定義されています。

### 🌟 重要なパラメータ
*   **`smoother_plugins`** (現在値: ["simple_smoother"])
    *   意味: 使用するスムーザーのプラグイン名を指定します。
*   **`simple_smoother.do_refinement`** (現在値: True)
    *   意味: パスの微調整・平滑化処理を実行するかどうか。滑らかな走行のために `True` にしておきます。

### 🔧 その他の基本パラメータ
*   **`costmap_topic`** / **`footprint_topic`**: 参照するグローバルコストマップとフットプリントのトピック名。
*   **`simple_smoother.tolerance`** (現在値: 1.0e-10) / **`max_its`** (現在値: 1000): スムージング計算時の許容誤差と最大計算回数。
*   **`use_sim_time`**: シミュレーション時はTrue、実機時はFalse。

# リカバリー・振る舞いサーバー (behavior_server)

ロボットが障害物に囲まれて動けなくなったり、経路が引けなくなった際に発動する「リカバリー動作（脱出動作）」を管理するノードです。

## 基本パラメータ

`nav2_params.yaml` 内の `behavior_server` 名前空間で定義されています。

### 🌟 重要なパラメータ（調整の頻度：高）
*   **`recovery_plugins`** (現在値: ["backup", "wait"])
    *   意味: 使用するリカバリー動作の順番と種類を定義します。現在は「少し後ろに下がる（backup）」→「その場で待機して障害物が退くのを待つ（wait）」の順に設定されています。
*   **`simulate_ahead_time`** (現在値: 2.0)
    *   意味: リカバリー動作（回転や後退）を実行する前に、衝突しないか先読みしてシミュレーションする時間(秒)。この値を大きくしすぎると計算負荷が高くなります。

### 🔧 その他の基本パラメータ
*   **`cycle_frequency`** (現在値: 10.0): サーバーの実行周波数(Hz)。
*   **`max_rotational_vel`** (1.0) / **`min_rotational_vel`** (0.4) / **`rotational_acc_lim`** (3.2): リカバリー（その場回転など）を行う際の回転速度と加速度の制限値。
*   **`use_sim_time`**: 実機時はFalse。
